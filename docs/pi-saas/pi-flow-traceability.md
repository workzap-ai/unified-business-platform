## How to read this

- Spec files are in `docs/pi-saas/spec-text/`. Line numbers are lines of those text files.
  `v1.6` = `pi-platform-spec-v1.6-2026-10-30.txt`, `spec-1` = `pi-platform-spec-1.txt`.
- Precedence applied (v1.6 lines 566-611, "Which rule wins when books disagree"): Constitution
  first, then Solution Mode and the value line, then voice, then industry packs, then learned
  examples. v1.6 wins over v1.5, v1.4 and the platform spec; Book 5 wins over Books 1-4 on the offer
  and on the ideas cap; Book 2 RANS/RSOL wins over Brain v3 RSELL01. `CLAUDE.md` says the same.
- Status: `implemented` only when a named test was run and passed on this tip (batch of 685 passed
  for the existing tests, 847 passed + 86 xfailed + 41 xpassed for the journey unit file, the
  integration journeys listed in the report). `partial` = implemented with a known gap (a journey
  that stays xfail). `prompt-only`, `missing`, `conflicts` as named.
- Tests named `journey:` are in `apps/api/tests/unit/test_pi_ps_flow_journey_checks.py` (U) or
  `apps/api/tests/integration/test_pi_ps_flow_journeys*.py` (I) over `tests/fixtures/ps_flow_journeys.json`.
